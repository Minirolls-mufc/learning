# Romeo 汉字课堂

本目录当前处于“新产品逻辑可用、页面尚未拆分”的验收节点。

## 目录

- `index.html`：页面结构、样式和页面级交互。页面模块拆分留到本轮验收之后。
- `data/content.json`：静态基础字表，包含分组、超级分组、全局字形配置和形近字组。
- `js/content-store.js`：内容规范化、静态基线与差量覆盖、旧整包迁移。
- `js/progress-store.js`：按汉字保存的学习和三阶段复习进度。
- `js/learning-engine.js`：重点字、认字候选、结构部件和笔顺候选规则。
- `js/review-engine.js`：按分组生成词语复习任务。
- `tests/logic.test.cjs`：数据迁移及学习、复习核心规则测试。

## 数据规则

- 单字默认是重点字；只有 `focus: false` 时不是重点字。
- 词语使用 `focusIndices` 保存零个、一个或多个重点字位置。
- `charDefs` 是全局字形库，值只保存红色笔画编号；空字符串表示全红。
- 词语编辑页逐字设置重点字和红色笔画，字形修改仍统一写回全局 `charDefs`。
- `similarGroups` 完全由人工维护，只用于认字题。
- 页面按“静态基础内容 -> 内容差量 -> 汉字进度”加载。
- 旧版云端整包会转换为相对静态字表的差量，旧 `ach.learnedChars` 不迁入新进度。

学习页以词语田字格作为固定语境，当前重点字用红蓝字形突出，其他字以中性字形保持显示。当前字依次完成认字、结构和全笔画排序；“认一认”可慢速播放笔顺，“选笔顺”不自动播放，完成后显示动画反馈并自动进入下一项。步骤控制始终使用固定的“上一步／辅助操作／下一步”三栏布局。

复习页先选择“按组、今日差一点、到期复习、历史高频”范围，再选择练习纸、形近字挑选、结构连连看或写字练习。前三种只用于巩固，不修改进度；写字练习在原田字格中展示或隐藏答案，逐字选择“正确／差一点”，并在整次练习结束后统一更新进度。只要词语配置了重点字即可直接写字练习，不要求先完成学习流程。

字词管理包含独立的“字形管理”标签页，可搜索或按分组筛选全部汉字，滚动时按需加载红蓝预览并直接编辑全局 `charDefs`。

当前静态基线有 101 个分组、1057 条内容和 807 个全局字形。现有单字按默认重点字迁移；现有词语默认没有重点字；形近字库初始为空。

## 本地运行

```bash
cd hanzi
python3 -m http.server 4174 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4174/?offline=1`。本地预览不会读写线上 JSONBin。
